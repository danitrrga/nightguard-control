# Quick Task 260612-gc2

Two user asks: (1) Nightguard Control should run on startup; (2) the curfew hook
must be enabled in ALL Claude projects (global), not just the LifeOS vault.

## Discovery (material — corrected prior "cutover complete" assumption)

- Global `~/.claude/settings.json` had **no** curfew hook. The guard was wired
  **only** in `LifeOS/vault/.claude/settings.json`, pointing at the **legacy**
  `curfew_guard.ps1` (not the new Phase-5 `nightguard_adapter.ps1`).
- => Prompt curfew was enforced ONLY inside the vault project. Every other
  project (incl. this repo) had no prompt gate. (Watchdog/StayFree still global.)
- No release exe, no Run-key, no Startup shortcut; window close quit the app.

## Decisions (user)
- Global guard = **legacy `curfew_guard.ps1`** (replicate what's live, just global).
- Startup = **Run-key + close-to-tray** (zero new deps).

## Tasks

### Task 1 — Globalize the curfew hook (ops, outside repo)
- Add `curfew_guard.ps1` to global `~/.claude/settings.json` `UserPromptSubmit`.
- Remove the duplicate from `LifeOS/vault/.claude/settings.json` (Claude merges
  hook scopes -> avoid double-fire); single global source.
- Safety: prove the guard exits 0 (allow) before AND after (daytime, outside the
  20:45 curfew); validate both settings files parse as JSON.
- verify: guard exit 0; both JSON valid; this session keeps working (live proof).

### Task 2 — Close-to-tray + hidden login start (repo code)
- `src-tauri/src/lib.rs`: `on_window_event` CloseRequested -> `prevent_close` +
  `hide` (background companion, quit via tray). Window starts hidden; a manual
  launch (no `--hidden`) shows it on ready.
- `src-tauri/tauri.conf.json`: main window `"visible": false` (no login flash;
  the late-`hide` race left `IsWindowVisible=true`, so start hidden in config).
- verify: `cargo check`; release build; smoke-launch `--hidden` ->
  `IsWindowVisible=false`, process resident.

### Task 3 — Autostart installer + register (repo + ops)
- `scripts/deploy/install_autostart.ps1` (new, parameterized, publishable):
  HKCU Run-key -> `"<exe>" --hidden`; `-Remove` to unregister.
- Register the live Run-key for this instance pointing at the release exe.
- verify: Run-key readback; smoke launch resident + hidden.

## Must-haves
- Curfew guard fires in every Claude project (global), single-source, allows now.
- App launches hidden-to-tray at login; closing the window hides (not quit).
- No personal paths baked into repo; installer is parameterized.
