<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| root watchdog tick → user Hyprland session | Root launches a user-session GUI process via runuser; crosses the privilege boundary into the user's Wayland session. |
| Late-night user → keep-alive supervisor | Adversary wants to quit StayFree to escape its blocking, or stop the supervisor. |
| StayFree rule store (user-editable, cloud-synced) → enforcement | NOT root-locked; reconfiguration is an open escape (accepted, D-06). |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-04 | Denial of Service (escape) | User quits StayFree to escape blocking | mitigate | Root-owned every-tick check-then-respawn via runuser bridge; lives in the systemd SYSTEM watchdog, so `systemctl --user stop` cannot disable it (NBLK-03-style un-stoppability). ≤60s cold-start leakage accepted. |
| T-09-05 | Tampering / scope | Keep-alive closes only the *quit* escape, NOT the *reconfigure-the-rule* escape | accept | Eyes-open per D-06: StayFree rules are user-editable/cloud-synced and deliberately NOT root-locked; the reconfigure escape remains open. Documented residual risk; rule-store root-lock is deferred. |
| T-09-06 | Elevation of Privilege | A root-launched closed-source Electron AppImage into the user session | mitigate | StayFree gets NO `.guardkey`/signing/config role; launched as the *user* (runuser drops privilege), not as root; Popen start_new_session detaches it.
