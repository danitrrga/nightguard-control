| omarchy theme files → TUI | World-readable desktop theme files parsed into colors; untrusted only cosmetically. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-05 | Spoofing | StatusScreen lock display | mitigate | Status sourced from `guard.curfew_verdict` + signed state; never local curfew math; advisory caption "status reflects what the guard will enforce"; never show OPEN when state dubious (UI-SPEC). |
| T-10-06 | Tampering | stale token meter across week boundary | mitigate | Meter uses `backend.tokens_left()` (lazy-reset `effective_spent`), never raw `weekly_spent` (Pitfall 4). |
| T-10-07 | Denial of Service | colors.toml absent after theme switch | accept/mitigate | Fallback to `alacritty.toml` (Pitfall 6); on total failure keep Textual's default theme rather than crash. Low impact (cosmetic). |
| T-10-08 | Information Disclosure | hmac display | accept | config/state hmacs are non-secret integrity tags; truncated for layout. Displaying them aids the user, leaks nothing the root files don't already expose (0644). |
</threat_model>
