<objective>
Stand up the greenfield Python Textual TUI package (`ngtui/`) inside this publishable product repo, and build `backend.py` — the single, load-bearing seam to the existing Python trust stack in the separate LifeOS repo. This plan establishes the "import, never re-implement" contract (PORT-02/03): the TUI reads state and the live verdict by importing key-less functions, computes the edit preview by importing the CLI's own classifier+quota, and commits only by shelling the sudoers-mandated `sudo` argv. It also runs the Wave-0 inline-sudo + theme-repaint spike to settle the two flagged runtime risks (A2/A3) before the screens are built.

Purpose: De-risk the backend seam and the inline-sudo TTY behavior first, so Waves 2-3 build UI against a proven adapter.
Output: `ngtui/` package skeleton, `backend.py` adapter, `app.py` shell, and a spike that confirms the suspend→sudo→resume flow.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| TUI process (user) → root signer | Unprivileged TUI shells `sudo nightguard_ctl.py commit`; the root key never enters the TUI. |
| TUI process → live config/state files | TUI reads root-owned `guard.json` (0644) + sanctioned config; writes ONLY via the root CLI. |
| TUI proposed-config temp file → root CLI `--from` | Untrusted-from-the-signer's-view config bytes cross into the signer, which re-canonicalizes + classifies them. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-01 | Information Disclosure | backend.py key handling | mitigate | TUI never calls `ngcommon.read_key()` (returns None for non-root anyway); computes no HMAC; key stays root:root 0600 (PORT-03). |
| T-10-02 | Tampering | preview vs signer drift | mitigate | `preview_change` imports the live `ctl.classify_change`/`quota_decide`; no vendored classifier — preview is byte-faithful to the signer (D-07). |
| T-10-03 | Elevation of Privilege | commit subprocess argv | mitigate | argv is the exact sudoers `Cmnd_Alias` shape `["sudo","/usr/bin/python3",<abs>,"commit","--from",tmp]`; no `shell=True`; no alternate interpreter path. |
| T-10-04 | Tampering | `--from` temp file race / symlink | mitigate | `tempfile.mkstemp` (0600, exclusive create), write, pass path, `os.unlink` after; the CLI re-canonicalizes the bytes it signs. |
| T-10-05 | Spoofing | optimistic lock display | mitigate | `live_verdict` returns `guard.curfew_verdict` (never local curfew math); state read from `guard.json`; advisory caption (UI-SPEC "State unverifiable"). |
| T-10-SC | Tampering | `uv pip install textual` | mitigate | slopcheck unavailable → Task 1 is a blocking-human legitimacy checkpoint verifying textual==8.2.7 on PyPI before install. |
</threat_model>
