<objective>
Build the EditScreen — the anti-impulse editing half of the TUI and the whole reason the product exists. The user edits the D-09 field set with single-key navigation; each staged change shows its tighten/loosen direction and token cost (computed by the signer's OWN classifier) BEFORE any authentication; a confirm gate states the consequence in one unmistakable line; and only on the explicit `y` keystroke does the TUI suspend, run `sudo nightguard_ctl.py commit --from <temp>`, and surface the CLI's verbatim result. Edits are composed as format-preserving per-field line edits on the sanctioned text so the bytes the HMAC signs are not disturbed (PORT-01 single-key + PORT-02/03 commit via sudo, no key, no second crypto).

Purpose: Deliver the front-loaded direction+cost preview and the inline-sudo commit — the core anti-impulse moment.
Output: `lineedit.py`, `widgets/edit.py` (EditScreen + ConfirmScreen), and the edit flow wired into `app.py`.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| TUI edit text → root signer (`--from` temp) | The proposed config bytes cross from the unprivileged TUI into the root CLI, which re-canonicalizes + classifies + signs them. |
| User intent → commit | The confirm gate + sudo prompt is the deliberate friction past the impulse threshold. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-02 | Tampering | preview vs signer drift | mitigate | Preview imports the live `ctl.classify_change`/`quota_decide` via backend; diff base is SANCTIONED (the CLI's base, Pitfall 5); never a vendored classifier (D-07). |
| T-10-03 | Elevation of Privilege | commit argv | mitigate | backend.commit uses the exact sudoers argv, no shell; edit values land in YAML text validated by the CLI's parser, never a shell (Injection mitigation). |
| T-10-04 | Tampering | `--from` temp file | mitigate | mkstemp 0600 exclusive; unlink after; CLI re-canonicalizes signed bytes. |
| T-10-09 | Tampering | YAML re-emit corrupting signed bytes | mitigate | lineedit.py does format-preserving per-field LINE edits only; no pyyaml/ruamel re-serialize; round-trip test asserts only the target field changed and ngcommon.yaml_load still parses. |
| T-10-10 | Spoofing/Repudiation | optimistic post-commit token decrement | mitigate | After commit, re-read `guard.json` (no local optimism); result line is the CLI's verbatim stdout/exit, never fabricated. |
| T-10-11 | Bypass of anti-impulse friction | confirm gate ordering | mitigate | Direction + token cost rendered BEFORE `suspend()`/sudo; `y` is the only trigger; 0-token loosen disables commit (UI-SPEC hard rule). |
</threat_model>
