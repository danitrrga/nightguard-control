**Atomic write with .bak + tmp→replace + validate** — reuse `write_atomic()` verbatim (lines 47-67). Do NOT hand-roll a second writer:
```python
def write_atomic(path, data):
    os.makedirs(os.path.dirname(path), exist_ok=True)
    bak = path + ".bak"
    if os.path.exists(path) and not os.path.exists(bak):
        try: shutil.copyfile(path, bak)
        except Exception: pass
    tmp = path + ".tmp"
    with io.open(tmp, "w", encoding="utf-8") as fh:
        json.dump(data, fh, ensure_ascii=False, indent=2)
    json.load(io.open(tmp, encoding="utf-8"))   # validate before swap
    os.replace(tmp, path)
```
