## Curfew allowlist

| Option | Description | Selected |
|--------|-------------|----------|
| Exact slash-commands only | config.yaml allow_commands; only exact match passes; hard to abuse | ✓ |
| Prefix match | Passes if prompt starts with an allowed token — looser, easy to bypass | |
| Use grace window instead | Drop planning allowlist; use the +8min grace bypass for real planning | |

**User's choice:** Exact slash-commands only.
**Notes (refinement):** Match on the **leading slash-command token**; the prompt passes with its
arguments intact. `/plan` must accept free-form parameters describing what/when to do tomorrow
(e.g. `/plan tomorrow: …`), and this must work for the **skill-backed** `/plan` command (the hook
sees the raw `/plan …` text). `/shutdown` passes the same way. Planner must VERIFY that
UserPromptSubmit fires and exposes the text for skill-backed slash commands — top integration risk.
