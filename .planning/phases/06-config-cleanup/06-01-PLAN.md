<objective>
Redefine the Rust direction-classifier's field table from the dead Windows app-blocking
model (`watchdog.apps` — a `uwp`/`package_id` list) to the Linux `blocking:` model
(`browser_extension` + `native_apps`), so that loosening/tightening of the new keys is
classified correctly and no product code carries the Windows shape.

Purpose: this is the **product half** of LXCF-01. config.yaml is signed as opaque canonical
bytes, so the schema change is transparent to signing — the only product code that *reads*
the blocking keys is this classifier table. Phase 8's native blocker will read
`blocking.native_apps.blacklist`; this plan establishes that path.
Output: an updated `FIELD_TABLE` + `//!` doc table in `classify.rs`, and tests proving the
new directions, with every `watchdog.apps`/`uwp`/`package_id` reference gone from the crate.
</objective>
