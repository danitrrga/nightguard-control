<objective>
Fold the native-app kill step into the **root** watchdog `tick()` (NBLK-01/02/03). On each
tick, while curfew is locked and no grace is active, enumerate Hyprland clients via the
verified `runuser` bridge, match their class against `blocking.native_apps.blacklist`,
SIGKILL the matched pids, append an audit line per killed pid to `watchdog.log`, and fire
one summary Spanish-butler notification.

Purpose: a late-night impulse cannot keep Steam/Discord open during curfew — the root tick
re-kills them within ≤60s, and because it lives in the root systemd *system* service it
cannot be stopped from user space.

Output: `_kill_native_apps(cfg)` + `_notify_user(...)` helpers and a verdict-gated kill step
wired into `tick()` between the browser-policy check and the `_log` summary, consuming the
Plan-01 `guard.curfew_verdict`.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| root watchdog → user Hyprland session | root crosses into /run/user/1000/hypr via runuser (CAP_DAC_OVERRIDE); enumerates + signals user-owned pids |
| blacklist entries / window class strings → subprocess | attacker-influenceable strings (config blacklist, hyprctl JSON class fields) flow toward the kill + notify commands |
| $HIS (HYPRLAND_INSTANCE_SIGNATURE) → env of runuser | discovered from /run/user/*/hypr/* basename each tick |
| guard.curfew_verdict → kill gate | the verdict decides whether root kills user pids |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-04 | Elevation | Command/arg injection via blacklist entry, window class, or $HIS into runuser/hyprctl/notify-send | mitigate | ALL subprocess calls use a list argv (`subprocess.run([...])`), never `shell=True` and never an interpolated shell string. Blacklist entries and class strings are used ONLY as Python-side substring comparands and as `notify-send` message *arguments* (not interpreted), so a class like `; rm -rf` cannot escape into a shell. $HIS is passed as an `env KEY=VALUE` argv token, not concatenated into a command. (Task-1 acceptance greps for absence of shell=True.) |
| T-08-05 | Elevation/DoS | PID-reuse race: a dedup'd pid is reaped + reassigned to an innocent process between enumeration and os.kill | accept-and-document | Window is the few ms between `hyprctl clients -j` and `os.kill`; on a single-user desktop the odds of a blacklisted pid being instantly reassigned to a critical process are negligible, and the worst case is one stray SIGKILL of a user process that the user can relaunch (the tool's whole premise is the user being able to relaunch). Documented accepted risk for v1; a future re-check (re-read /proc/<pid>/comm before kill) is the mitigation if it ever bites. |
| T-08-06 | Elevation | Kill gate fails OPEN (kills outside curfew / during grace) on a verdict error | mitigate | The gate kills ONLY on the explicit allowlist {locked, clock_tamper, offline_blocked}; any other value, None, or exception falls through to the suppressed (no-kill) branch. Task-2 asserts an exception suppresses the kill. The verdict reuses guard's existing fail-closed-toward-locked posture (in_curfew except→True) so a config-parse failure denies sessions but the KILL still only fires on a definite locked verdict — it never widens kills on uncertainty. |
| T-08-07 | Tampering/Injection | Notification + watchdog.log content injection from window class strings | mitigate | Class strings reach notify-send as an argv message argument (no shell), and reach watchdog.log via the `_log("%s %s")` formatter (plain file append, newline-delimited); a class containing a newline could forge a log line — low impact (local audit only, not a trust boundary), accepted. notify-send renders text, not markup that escalates. |
| T-08-08 | DoS | Enumeration/kill crashes or hangs the root tick (blocking config-revert) | mitigate | Every subprocess.run uses a `timeout`; the whole kill path is wrapped in try/except returning [] on any failure (08-NOTES no-Hyprland no-op); the kill runs AFTER verify_and_revert + browser-policy so a kill failure cannot block the integrity revert. |
| T-08-SC | Tampering | package installs (npm/pip/cargo) | n/a | This plan installs NO packages — pure-stdlib Python (os/signal/glob/subprocess/json) edit to an existing module. No legitimacy gate required. |
</threat_model>
