<objective>
Fold the native-app kill step into the **root** watchdog `tick()` (NBLK-01/02/03). On each
tick, while curfew is locked and no grace is active, enumerate Hyprland clients via the
verified `runuser` bridge, match their class against `blocking.native_apps.blacklist`,
SIGKILL the matched pids, append an audit line per killed pid to `watchdog.log`, and fire
one summary Spanish-butler notification.

Purpose: a late-night impulse cannot keep Steam/Discord open during curfew — the root tick
re-kills them within ≤60s, and because it lives in the root systemd *system* service it
cannot be stopped from user space.

Output: `_kill_native_apps(cfg)` + `_notify_user(...)` helpers and a verdict-gated kill step
wired into `tick()` between the browser-policy check and the `_log` summary, consuming the
Plan-01 `guard.curfew_verdict`.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| root watchdog → user Hyprland session | root crosses into /run/user/<uid>/hypr via runuser (CAP_DAC_OVERRIDE); enumerates + signals user-owned pids; the username is derived at runtime via pwd.getpwuid, never hardcoded |
| blacklist entries / window class strings → subprocess | attacker-influenceable strings (config blacklist, hyprctl JSON class fields) flow toward the kill + notify commands |
| $HIS (HYPRLAND_INSTANCE_SIGNATURE) → env of runuser | discovered from /run/user/*/hypr/* basename each tick |
| guard.curfew_verdict → kill gate | the verdict decides whether root kills user pids |
| signed state (guard.json) → kill gate | tick() worst-cases state.grace to None on a state_hmac mismatch before the verdict, so a forged grace cannot suppress the kill |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-04 | Elevation | Command/arg injection via blacklist entry, window class, $HIS, or username into runuser/hyprctl/notify-send | mitigate | ALL subprocess calls use a list argv (`subprocess.run([...])`), never `shell=True` and never an interpolated shell string.
