<objective>
Refactor `guard.py` to expose a **side-effect-free curfew verdict** (D-09) that the
Phase-8 watchdog native-kill gate can consume — without re-running `verify_and_revert`
(the watchdog already calls it) or `_verdict`/`append_audit` (guard's HMAC audit chain).

Purpose: D-08 requires the native-kill gate to use the SAME full verdict guard uses
(curfew window + daily grace + NTP true-time + clock-tamper + `block_when_offline`).
D-09 forbids copy-pasting that math or double-firing guard's side effects. The only
correct shape is a single pure function the watchdog and `decide()` both call.

Output: a new pure `curfew_verdict(cfg, state, key=None)` in `guard.py`, returning a
verdict string (`locked` / `grace_active` / `outside_curfew` / `clock_tamper` /
`offline_blocked`); `decide()` re-expressed in terms of it so the curfew math is defined
once and the hook path's JSON + exit contract is unchanged.
