| Boundary | Description |
|----------|-------------|
| Hand-editor -> config.yaml | Untrusted out-of-band edit; the guard's HMAC verify is the enforcement point |
| App commit (lock held) -> guard fire | A guard fire mid-commit must not revert a legitimate write |
| Tampered guard.json -> guard runtime | Forged state must yield worst-case, never a loosen |
| Corrupted both files -> guard | Double-corruption must brick toward lockout, never open |
