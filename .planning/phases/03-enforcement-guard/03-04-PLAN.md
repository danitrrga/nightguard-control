<objective>
Ship the in-repo integrity mechanism (D-10 / GARD-06): a new verify_hook_integrity.ps1 that
records the SHA256 of the guard scripts in a committed baseline manifest and alerts on drift,
self-registering both nightguard_guard.ps1 and verify_hook_integrity.ps1. This is Wave 4
because it must hash the COMPLETED guard scripts produced by plans 02-03 — registering them
before they are final would bake in a drifting baseline.

Purpose: GARD-06 makes altering or removing the guard itself detectable — closing the
"disable the enforcement script" attack on a self-binding tool. Keeping it in-repo (not
deferred to the personal host) makes the acceptance criterion verifiable inside this repo.

Output: scripts/guard/verify_hook_integrity.ps1 (an -Update baseline writer + default drift
checker) and the committed scripts/guard/guard.baseline.sha256 manifest.
</objective>

    Create scripts/guard/verify_hook_integrity.ps1, ASCII-only, with the nightguard_interop.ps1
    header style (Set-StrictMode -Version Latest; $ErrorActionPreference = 'Stop'). Add a param
    [switch]$Update. Define the registered set as the relative paths of the guard scripts to
    protect: scripts/guard/nightguard_guard.ps1 AND scripts/guard/verify_hook_integrity.ps1 (it
    self-registers so altering EITHER alerts). Resolve $here = Split-Path -Parent
    $MyInvocation.MyCommand.Path and the repo root for stable relative paths.
    For each registered path compute $hash = (Get-FileHash -Algorithm SHA256 -Path $abs).Hash.ToLowerInvariant()
    (Get-FileHash reads raw bytes -> no EOL-normalization risk).
    -Update mode: write scripts/guard/guard.baseline.sha256 with one line per registered script in
    the form "<sha256><two spaces><relative-path>" (forward-slash relative paths, ASCII, LF line
    endings), then print what was written and exit 0.
    Default (verify) mode: read guard.baseline.sha256; for each manifest entry recompute the
    SHA256 and compare; any mismatch, any registered file missing on disk, or any manifest line
    whose file no longer exists -> Write-Host an alert naming the drifted/missing path and collect
    a failure. Also flag a registered script that is NOT present in the manifest (added-but-unbaselined).
    Use the Add-Check / === Summary === pattern; exit 0 only if every registered script matches its
    baseline, else exit 1.
    Then run the script once with -Update to generate scripts/guard/guard.baseline.sha256 against
    the FINAL plan-02/03 guard scripts, and commit that manifest as the checked-in baseline.
  </action>
  <verify>
    <automated>powershell -NoProfile -ExecutionPolicy Bypass -File scripts/guard/verify_hook_integrity.ps1; if ($LASTEXITCODE -ne 0) { exit 1 }</automated>
