| Boundary | Description |
|----------|-------------|
| System clock -> grace verdict | The user is admin and can move the clock; the verdict must use independent true time |
| Network egress -> SNTP | An offline/isolation trick must not hold a grace window open |
| guard-audit.log on disk -> next run | Deleting/editing/truncating the log must be detectable |

| T-03-14 | Information disclosure | verdict JSON leaking secrets | accept | The JSON carries only decision/reason/remaining/reverted/fail_closed — no key/state bytes (D-02 shape). |
| T-03-15 | Spoofing | guard honoring grace under worst-case state | mitigate | Task 1: plan-02 worst-case ($graceUsed=true) forces deny regardless of window. GARD-03+GARD-04. |
