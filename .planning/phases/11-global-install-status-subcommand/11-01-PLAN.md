<objective>
Build and unit-test the key-less status core for `ngtui status --json`: a pure
`status.py` builder that maps a guard verdict + token count + state into a
Waybar-shaped `{text,tooltip,class}` object, plus a `backend.cache_only_verdict()`
seam that resolves the verdict WITHOUT ever triggering a synchronous NTP/HTTP query
(Pitfall 1). All logic here is headless-testable — no TTY, no subprocess, no argv.

Purpose: DESK-02's load-bearing contract (key-less, fail-closed, single-source-of-truth
verdict math) lives in pure functions so Plan 02's `__main__` router is thin glue.
This mirrors Phase 10's `verdict_display`/`token_meter` pure-helper pattern.

Output: `ngtui/ngtui/status.py` (new pure module), a `cache_only_verdict` helper in
`backend.py`, the Wave-0 test fixtures in `conftest.py`, and the headless test file
`test_status_cli.py`.
</objective>

| Boundary | Description |
|----------|-------------|
| trust-stack import → `ngtui` | `NIGHTGUARD_STACK_DIR` chooses which `nightguard_ctl.py`/`guard.py` get imported (untrusted env crosses here) |
| `ngtui status` read → eventual Waybar exec | the JSON the bar renders crosses out of the process |
| network (NTP/HTTP) → `true_unix()` | a cold cache reaches the network; the status path must not depend on it |
