<objective>
Wire the tested status core into the entry point: add an argv front-controller to
`__main__.py` that routes `ngtui status [--json]` → the head-less key-less reader
(emit single-line JSON, always exit 0, fail closed to `unavailable` on ANY error),
and routes bare `ngtui` → the TUI behind a `sys.stdin.isatty()` loud-fail guard, with
`textual`/`ngtui.app` lazily imported only on the TUI branch.

Purpose: closes DESK-01 (the `pyproject` `[project.scripts] ngtui` shim now has a
status subcommand to route to) and DESK-02 (the key-less `status --json` emitter),
and the SC-4 TTY guard. The import of `ngtui.backend` lives INSIDE the status
try-block so a bad `NIGHTGUARD_STACK_DIR` import-time `RuntimeError` degrades to
`unavailable` instead of crashing (Pitfall 2).

Output: the modified `__main__.py` router + the remaining router tests appended to
`test_status_cli.py`.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| env (`NIGHTGUARD_STACK_DIR`) → `import ngtui.backend` | a poisoned/missing stack path crosses at import time inside `_status` |
| `_status` stdout → eventual Waybar exec | the JSON object the bar parses crosses out here |
| stdin TTY presence → TUI launch | a non-TTY stdin (Waybar exec, pipe) must not start the escape-code-spewing TUI |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-05 | Denial of Service | a crashing `status` exec breaks the eventual Waybar module | mitigate | `_status` catches `Exception` broadly, emits `UNAVAILABLE`, returns 0 ALWAYS. Acceptance: test_status_exit_zero_on_arbitrary_error, test_status_fail_closed_on_bad_stack. |
| T-11-06 | Tampering / EoP | import-time `RuntimeError` from a poisoned stack bypassing the fallback | mitigate | `import ngtui.backend` is INSIDE the `_status` try-block (Pitfall 2). Acceptance: test_status_fail_closed_on_bad_stack (import re-runs, degrades to unavailable). |
| T-11-07 | Spoofing / DoS | head-less `status` accidentally launching the interactive TUI / TUI launched with no TTY spewing escapes | mitigate | `sys.stdin.isatty()` guard on the TUI branch ONLY; status routed before it. Acceptance: test_tui_requires_tty, test_status_does_not_import_textual. |
