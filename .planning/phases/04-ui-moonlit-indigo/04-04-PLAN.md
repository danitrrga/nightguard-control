<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| get_state DTO → DOM render | The re-verified state crosses into presentation; render must not re-add optimism |
| data dir file events → watch callback | External file changes (guard revert, hand-edit) drive re-reads |
| bundled assets (fonts) | Local woff2 only; no remote asset fetch |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-14 | Spoofing | 1s tick flips status to OPEN when the boundary passes (false unlock) | mitigate | The tick re-renders ONLY countdown digits; it never recomputes/sets the status word. A passed boundary shows 00:00:00 and waits for the watch-driven re-read of re-verified state (D-05). |
| T-04-15 | Spoofing | render shows optimistic tokens/grace after a local edit | mitigate | render derives solely from a freshly invoked get_state DTO; the !state_verified branch shows fully-locked "State unverified" copy; no local state mutation (D-03/D-09). |
| T-04-16 | Tampering | remote CDN font/asset injection | mitigate | Roboto woff2 bundled locally; no remote URLs in CSS/HTML (Pitfall 6); webview loads no remote content. |
| T-04-17 | Elevation of Privilege | over-broad fs:scope `**` | mitigate | fs:scope narrowed to the resolved data dir (Pitfall 5); only watch/unwatch fs permissions granted. |
</threat_model>
