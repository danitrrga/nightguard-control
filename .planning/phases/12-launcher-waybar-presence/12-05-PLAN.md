        `grep -qF ">>> $marker_id" "$file"` → already merged, return 0

        (line-based append is safe).
    (4) style.css: `inject_block "$NG_WAYBAR_STYLE"` appends the css block.
    (5) config.jsonc (JSONC — TEXT only): if the guard marker absent, backup then
        text-insert the module object before the final top-level `}` (guarded),
        AND insert `"custom/nightguard",` into the `modules-center` array right
        after the `"clock",` anchor — each guarded by its own "already present?"
        grep so a re-run never double-inserts. No `jq`.
    (6) .desktop: `install -m644` nightguard.desktop → `$NG_APPLICATIONS_DIR`.
    (7) Icon: loop sizes 16 32 48 64 128 256 512 → `install -d
        "$NG_ICON_BASE/${S}x${S}/apps"` + `rsvg-convert -w $S -h $S
        icons/nightguard.svg -o …/org.omarchy.ngtui.png`; `install -d
        "$NG_ICON_BASE/scalable/apps"` (dir absent live — create) + copy the SVG
        as `org.omarchy.ngtui.svg`.
    (8) ngtui-menu: `install -m755` bin/ngtui-menu → `$NG_BIN_DIR`.
    (9) Cache refresh: `gtk-update-icon-cache -f -t "$NG_ICON_BASE"` (`-t`: user
        hicolor dir has no index.theme) + `update-desktop-database
        "$NG_APPLICATIONS_DIR"`.
    (10) Reload (skip when `NG_SKIP_RELOAD`): `pkill -SIGUSR2 waybar` (fallback:
        note a full waybar restart may be needed — execution-time check) +
        `hyprctl reload`.
    Emit a clear per-step log; on any injected block, print "backed up to
    <path>". Do not hardcode `$HOME` where an env var is provided.
