Sketch 002 · E, less terminal

E1 · No boxes — one keyline grid

Axis: remove the boxes. The six tiles keep their positions and lose their outlines. One layout: grid with keyline: thin $foreground 20% draws a line only between cells, so the screen reads as a set of regions on a shared grid instead of six drawn rectangles. The countdown is Textual's own Digits — thin box strokes, not blocks. Every meter is a solid background fill on whole cells, so there is no glyph texture anywhere. Closest reference in the library: Geist's hairline cell grid.

E2 · Air — fewer facts, wider margins

Axis: remove the density. Same regions, half the content. Two rows of padding inside every region, no rules inside them, four regions instead of six, and the countdown is plain bold text with no large figures at all — the space around it does the work. Grouping by whitespace, not by chrome. This is the minimalist-editorial family's actual thesis, tested honestly: if it works here, the large figures were never needed.

E3 · Solid chrome — filled headers and an accent spine

Axis: make the chrome solid rather than drawn. Each region gets a real filled title bar (border: panel → ▊█▎) the way a GUI window has one, and the state region carries a solid accent spine (border-left: tall → ▊) instead of a full outline. Bold Digits. The most ink of the three, and the furthest from a terminal — at the cost of being the busiest. Watch whether the filled headers read as software or as decoration.
